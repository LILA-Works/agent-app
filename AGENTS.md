# Agent Instruction

## Rules for Agents

Keep the following in mind when interacting with the developer.

- ALWAYS keep your responses concise and to the point.
- Do not make assumptions, surface ambiguity if any.
- When writing docs, trim prose to minimize restatement, hedging, or anything else the user cannot act on or does not present new information. State each fact once, and reference it from elsewhere.
